# 04 · 素材、切图与权利边界

## 原始素材已全部保留

`dist/assets/saved-01.jpg` 至 `saved-21.jpg` 是用户提供的 21 张收藏截图，按原字节复制。作者 / 标题 / 分类 / 时长 / 图片尺寸与裁剪坐标的逐条映射在 `manifests/assets.json` 和 `collection.json`。图片中的浏览器 UI、作者头像、点赞数字没有被当新产品自己的组件。

`assets/covers/saved-XX-cover.png` 是按原坐标提取的封面，PNG 无损编码，不重绘图片、不美化、不替换主体。原代码为了避免重复资产仍用原 JPG + CSS 偏移；重构时可用裁剪 PNG、按索引保留正确比例，不要把完整社交帖子截图塞进封面而重复下方标题。

第一批最后那张书本示意图、后续旧页面截图和外部参考图仅是历史说明，不是现行运行的资源；其关键视觉在当前代码与新生成截图中已经完整保留。包内没有一份重复、过时的“28条演示收藏”数据。旧 .git 历史不是复刻依赖。

## 程序生成素材

所有实际使用的原生插画与图标可以从源代码再导出：`npm run export-assets`。有原 SVG 和透明 PNG @2x/@3x：扭蛋机、拆开的蛋、红色完成花、六种类别 / 兜底插画、八个线性 UI 图标、原 favicon。

纸签、日记纸页、照片边、胶带、折角、阴影和按钮由 CSS 生成，原 CSS 已附，不需要 AI 生成图片才能复刻。UI chrome 应继续用代码；切图不是用于把文字和可点击组件拍扁。

## 字体

仅附 Noto Sans SC 开源备用字体与许可证；系统商业字体不附。具体授权和使用方式见 `03-visual-and-fonts.md`。页面截图、机器整句文字的参考图不等于授权提取字库，不能从截图反向制作字体文件。

## 当前没有的材料

- 没有原帖真实链接、完整视频、音频、图文正文、字幕、精确配方、运动完整课程。
- 没有实时搜索 API、AI 模型调用、服务端数据库、密钥、账号会话、小红书登录信息。
- 没有真实用户上传的日记照片 / 文字 / 链接绑定。验收截图使用隔离测试数据，只作视觉与状态示例，不要默认 seed。
- 没有把旧部署身份或 Sites 凭据复制到新平台。源码与文档足够本地复刻，不需要访问旧私有站点。

## 防止文件遗失

`manifests/canonical.sha256.json` 校验原始 28 个生产文件；`files.sha256.json` 校验本包所有交付文件（自身除外）。运行 `npm run verify`；裁剪尺寸和来源映射也在 assets 索引中。文件名用稳定 ID，中文标题只在数据里。
