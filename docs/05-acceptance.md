# 05 · 复刻验收

## 环境和运行

从迁移包根目录：

```sh
node scripts/serve.mjs
# http://127.0.0.1:4917/
```

网页不需安装任何 npm 依赖，加载的脚本、图片、字体均在本地。默认原版不用字体文件。网络断开后核心交互仍可运行；真实原帖新页是外部网站，需要网络和原站登录条件。

交互测试（另一个终端保持服务器）：

```sh
npm install
npx playwright install chromium
npm run qa
```

端口冲突时更换 `NEXT_NOW_PORT`；测试端口同时设置 `NEXT_NOW_BASE_URL`。使用已安装 Chrome 可指定 `NEXT_NOW_BROWSER` 绝对路径。`NEXT_NOW_MODULE_DIR` 仅是离线 / 预装测试库的备用定位，不需要按原作者的电脑路径设置。

PowerShell 示例：

```powershell
$env:NEXT_NOW_PORT='4926'
node scripts/serve.mjs
# 在另一个终端：
$env:NEXT_NOW_BASE_URL='http://127.0.0.1:4926'
npm run qa
```

## 手动视觉验收重点

1. 首页黄色合并页面；标题和扭蛋机居中，两个小入口不换标题行；没有旧底部介绍。
2. 目标页六卡三列、每张可选，选择后边框四边都完整；自填输入 / 空态正确；没有“现在什么状态”。
3. 纸签结果封面 / 原标题一一匹配；没有旧顶栏；按钮等宽；封面点入来源；手工 / 美食显示材料，其余不显示。
4. 原材料缺失不放行；新方法需显式读 / 确认，并显示 Demo；不能把原封面误标成假方案作者真实帖。
5. 开玩初始只有一个完成按钮；打卡后出现弹层，再想想后灰色不可重复完成且保留记录入口。
6. 编辑页一张暖纸，照片按钮有文字，一次多选最多 5 张，横线跟文字行高一致，纸内两个操作按钮。
7. 日历默认在上、时间轴在下，纯红花无黄心、红日期、没有重叠；纯文字记录不使用原收藏截图作缩略图。
8. 字体、emoji 和日期可能随平台 / 当天变化；抽取随机结果不一定等于截图。先比布局与状态，再按来源和素材 ID 核对，不误判为丢图。

## 测试数据不能成为用户初始内容

来源绑定用 `qa-only-not-a-real-note` 的拦截假地址，仅用于验证跳转。截图显示的照片和过去日期记录是自动验收 fixtures。真实 app 默认日记空；只在用户开始后创建记录。

## 修改之后如何交付

不要只说“看起来一样”。汇报实际测试、移动宽度、功能差异、是否仍仅本地假实例。校验原始文件哈希是保护迁移基线，开发后不要求哈希相同；真正等价以交互和视觉验收为准。重构不得用删除测试断言来制造通过。
