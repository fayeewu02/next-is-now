# 01 · 产品和页面

## 产品定位

把“收藏了以后做”的内容，转化成一次现在可开始的小体验。扭蛋负责降低选择成本；时间与材料确认降低启动障碍；打卡与日记留下生活反馈。是移动 H5 Demo，不是完整收藏同步平台。

## 当前已实现页面

| 内部 route | 页面 | 关键组件 / 渲染函数 |
| --- | --- | --- |
| home | 合并首页 | `renderHome`：黄色 hero、大标题、扭蛋机、两入口 |
| config | 目标 / 时间选择 | `renderConfig`：时间 chips、六分类、自填目标 |
| spinning | 扭蛋动画 | `render` 分支；850ms，减少动画时 100ms |
| result | 收藏纸签 | `renderResult`：拆蛋装饰、原封面、标题、描述、估时、条件材料清单、双按钮 |
| empty | 无匹配 / 本轮耗尽 | `renderEmpty`，支持改条件或重新装一轮 |
| start | 开玩 | `renderStart`：左缩略图、右内容和准备步骤，完成按钮 / 后续记录入口 |
| editor | 灵感记录 | `renderEditor`：一本日记的一页，照片、横线文字、存起 / 再想想 |
| diary | 我的日记 | `renderJournal` + `renderCalendar` + `renderTimeline`：月历默认、时间轴在下方 |

这些是内存状态，不是 URL 子路由。刷新回首页但本地已保存日记还在。不要把地址栏或截图文件名推断成新增路由。

## 首页和条件

标题整体上方居中、分层错落：把收藏夹的 / “下次一定” / 扭成“就是现在”！。红色为“就是现在”强调。扭蛋机为代码生成 SVG，不是图片背景。两个紧凑入口粉色 / 蓝色并排，icon、标题同一行。

我有目标需时间和方向；随机灵感默认半小时直接扭，结果估时按钮可返回修改。时间值：15、30、90、0（0 = 不限）。显示「半小时」但数据是 30。分类手工 / 阅读 / 播客 / 运动 / 美食 / 自填项，后者不是一个真实收藏类目。

21 条内容包含手工 8、阅读 1、播客 2、运动 2、美食 6、生活技能 2。生活技能通过自填项（编发 / AI / skill / 照片等）或随机出现，无单独的首屏类目。准确字段与估时详见 `manifests/collection.json`；旧封面标题有截断的条目已明确保留可辨认范围。

## 结果和开玩

结果整体是一张纸签，上方小扭蛋机 / 拆开的蛋，中间封面，下方文字详情。双等宽胶囊按钮：红色「就它，开玩！」、蓝色「再扭一个」。不要旧“这颗有点意思”或“30分钟以内·随机灵感”顶栏。保留可点击估时，它不是被删除的旧顶栏。

只有手工、美食需要材料。阅读、播客、运动不要求“看看手边有什么”。原材料由封面推测，初始勾选表示假设手边有；用户取消表示缺失。原封面和作者真实截图来源，推荐替代标题另标为演示。

开玩页面没有泛化的折叠步骤。左为原收藏小缩略图，右为封面摘要 / 三步准备与体验建议。摘要显示「AI 整理 · 基于封面」，不是实时调用 AI，也不是原视频完整提炼。来源未绑定时点击看截图并关联链接；已关联可以打开原站。

## 打卡和记录

开始后仅创建“已开启”，不会立刻亮花。完成按钮打卡后写入完成时间并弹出动画；记录是可选后续，不强迫记录。直接打开旧的未完成日记记录时保留旧约定：自动记为完成（单条、method=record），不批量处理。

记录页所有操作在一张纸中：日期 / 标题、一个明显加照片按钮、最多 5 张缩略图、带横线文字、主「存起来」与副「我再想想」、原收藏参考及删除。不限必须填写；文字和照片可以都空。

个人中心暖黄纸、胶带、生活碎片感。默认月历，向下为时间轴；顶部可切换只看时间轴。日期选择筛选当天，清除筛选看全部。只展示真实上传的第一张图片，更多图片显示数量，没照片就文字。

## 未实现，不要误补成已实现

没有小红书账号授权或自动收藏导入、真实在线缺料搜索、完整视频播放与识别、后端、云同步、多人共享、购买材料、提醒服务。已有产品扩展提案在 `original-notes/`，仅供以后决策。
