# 缺料替代方案：仅模拟实例

用户明确选择「Demo 做假的实例」，本轮没有接搜索后端、没有安装搜索插件，也没有 API / 模型搜索调用。

## 交互闭环

取消必需材料 → 帮我找替代方法 → 短暂模拟查找 → 显示模拟帖子 → 查看新清单、变化点与时长 → 勾选接受材料和效果变化 → 用这个方案 → 更新准备清单 / 标题 / 步骤 / 时间 → 开玩 → 保存选定方案的日记。

结果、账号、步骤、时长皆为虚构演示。界面全程标注「Demo 模拟 / 模拟帖子 / 演示预设」，不提供伪造的真实帖子地址，不归因于原收藏作者。原图留作灵感参考，采用后的卡片明确说明图片不是新方案成品。

## 实例

| 原灵感 | 缺料 | 演示新方法 | 预设时长 |
| --- | --- | --- | --- |
| 不织布蛋糕相框 | 针线 | 免缝粘合版，需要布艺胶 | 120 分钟 |
| 不织布蛋糕相框 | 针线或不织布 | 纸相框，另需彩色厚纸与纸艺胶 | 30 分钟 |
| 拼豆相框 | 拼豆 / 模板 / 熨烫相关工具 | 像素纸片相框，成品不同 | 30 分钟 |
| 小楷 / 篆书练习 | 宣纸 | 普通纸短时练习，吸墨效果不同 | 18 分钟 |
| 皮蛋肉酱拌面 | 皮蛋 | 无皮蛋肉酱拌面，口感改变 | 25 分钟 |
| 皮蛋肉酱拌面 | 皮蛋 | 番茄肉酱面，另需番茄且时间更长 | 35 分钟 |
| 抹茶草莓大福 | 抹茶 | 原味草莓大福，颜色与风味改变 | 65 分钟 |
| 芝士虾滑培根卷 | 培根 | 芝士虾滑小食，不再做培根卷 | 30 分钟 |

表中时间仅是 Demo 预设值，不是可靠的实际耗时。食品示例未补写比例、温度、熟制时间，也不能拿虚构步骤直接烹饪。

## 守卫

- 未确认新材料 / 效果，采用按钮禁用；关闭帖子不切换。
- 缺料组合必须全部被实例覆盖；例如缺皮蛋且缺肉，没有仅解决皮蛋的伪匹配。
- 新方案可能需要别的材料，不认为它们天然就有；必须确认新清单。
- 原先取消的可选材料不重新加入。
- 35 分钟方案不能在 30 分钟预算下直接开始；18 分钟练字同理。
- 原材料变化会清除选择并取消过期模拟查找；返回或再抽同样不回填旧结果。
- 可重新选方案、恢复原方案；暂时没有实例时明确说明，不编造任意替代。

## 保存与来源

确认开始时，记录新标题、新清单、新时间、新步骤、demoAlternative 快照；原收藏来源单独保留。开玩页优先使用采用的演示步骤，不把原视频摘要混入新方案；模拟帖子可只读回看。日记存好后刷新仍保留方案，不额外创建重复记录。

## 验证与实现

六组回归入口 scripts/qa.mjs。新检查 scripts/qa-alternatives.mjs；截图 / 结果在 qa/demo-alternatives/。已覆盖手工与美食、拒绝与采用、新材料、超时、恢复、多缺料无实例、过期状态、日记与刷新、320 / 390 / 1440px 布局。独立测试浏览器未访问任何外部搜索服务，也未改动用户浏览器数据。

沿用既有参考界面，以 image-to-ui-skill 的局部实现 / 实际截图核验流程完成，单人执行；Sites 保留原项目身份与私有访问范围。卡片、弹窗和模拟 loading 为 HTML / CSS，封面复用项目现有 SVG 示意图，不新增位图或伪装真实帖图；箭头 / 对勾继续通过统一 icon(name)。新增触控按钮至少 44px。

## 快速体验

1. 我有目标 → 不限时间 → 自填项「蛋糕」→ 取消针线 → 找替代 → 查看纸相框 → 确认 → 用这个方案。
2. 我有目标 → 半小时 → 美食 → 取消皮蛋 → 找替代 → 选择无皮蛋或番茄版 → 确认；番茄版会要求延长时间。
