## 来源与视觉

原始 JPG 文件保留完整内容，并逐一核对 SHA-256。结果卡仅用 CSS 展示封面区域，不改写图片；完整截图可在来源弹层查看。标题与作者来自截图；截图不完整的昵称保留省略号。不虚构收藏日期，不声称已取得原文、视频、音频或精确配方。
